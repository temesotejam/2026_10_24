# CHRONICLE — 歴史の奔流

実際の出来事・技術・制度・環境変化をカードへ落とし込んだ、一人用の歴史カードバトルです。

## プレイ

[GitHub Pagesでプレイ](https://temesotejam.github.io/2026_10_24/)

## ルール

- 毎ターン、時代力以内のカードを1枚選びます。
- 以前使ったカードとタグが重なると、連鎖ボーナスが発生します。
- 影響力を20まで高めるか、相手の安定を0にすると勝利です。
- 各カードの「史実」欄から、概要と外部の参考資料を確認できます。
- 「現実をカード化」から、身近なニュースを出典付きカードとして追加できます。追加カードはブラウザ内に保存されます。

カード効果は史実の因果関係をゲーム用に抽象化したもので、出来事の価値判断や被害規模そのものを数値化したものではありません。

## ローカル起動

依存関係はありません。

```bash
python3 -m http.server 4173
```
