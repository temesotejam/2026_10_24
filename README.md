# 雨を食べる庭

現実の天気と呼吸する、小さな庭のビジュアル・プロトタイプです。

## プレイ

[GitHub Pages で庭を開く](https://temesotejam.github.io/2026_10_24/)

## 起動

依存関係はありません。リポジトリ直下で次を実行してください。

```bash
python3 -m http.server 4173
```

その後、ブラウザで `http://localhost:4173` を開きます。

## 操作

- 「撫でる」「雨を呼ぶ」「種を置く」で庭に記憶を残します。
- 庭やルゥを直接クリックしても反応します。
- 5つの記憶が集まると、ルゥが進化します。
- 右上の音符ボタンで小さな効果音を有効にできます。
