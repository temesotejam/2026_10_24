# 現象救助隊 — REALITY DUNGEON

現実の現象や小さなニュースから、毎回形の変わる迷宮を作る一人用探索ゲームです。

## プレイ

[GitHub Pagesでプレイ](https://temesotejam.github.io/2026_10_24/)

## 基本ルール

- 矢印キー / WASD、または画面の方向ボタンで移動します。
- プレイヤーが1回行動すると、仲間と敵も1回ずつ行動します。
- 敵のいる方向へ進むと通常攻撃になります。
- 「観測」した現象を倒すと、最大3体まで仲間になります。
- 携帯食で空腹、救護メモでHPを回復できます。
- 光る階段を探し、3Fから脱出すると調査成功です。
- 入力したニュースは次の迷宮の色、出現する現象、観測ノートに反映されます。
- 各階には実際の記事が「現実地点」として出現し、接触すると見出し・確認済みの事実・出典を表示します。
- ニュース分野は直接ゲームへ作用します。地域は回復、環境は熱だまりの弱体化、交通は地図開示、科学は攻撃・技能強化になります。
- 地域・科学・交通・環境の公開ニュースをGitHub Actionsで6時間ごとに自動収集します。
- 事件・事故・災害などの見出しは自動除外し、記事本文は複製せず、見出し・日時・出典リンクだけを保持します。

## ニュース更新

`.github/workflows/news.yml` が公開RSSを取得し、`data/news.json` を自動更新します。取得できない場合は直前のデータを残すため、ゲームが壊れることはありません。Actions画面から手動実行もできます。

探索・ターン進行・仲間化・空腹・ランダム生成という骨格は、『ポケモン不思議のダンジョン 赤の救助隊』の逆コンパイルで明らかになった設計を研究対象にしています。任天堂・株式会社ポケモン等のコード、画像、名称、音声は使用していません。

参考: [pret/pmd-red — Pokémon Mystery Dungeon: Red Rescue Team decompilation](https://github.com/pret/pmd-red)
