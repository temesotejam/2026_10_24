# PARADOX ARCHIVE

実在した技術・制度・思想の「働き」をカード能力にした、一人用デッキ構築バトルです。

## プレイ

[GitHub Pagesでプレイ](https://temesotejam.github.io/2026_10_24/)

## 基本ルール

- 行動力3で手札を使い、検閲者の整合性を0にすると勝利です。
- 敵の次行動は常に公開されます。
- 防御は次の攻撃を軽減します。
- 証拠と勢いを蓄積すると、産業カードの攻撃が強化されます。
- 恒久制度は最大3枚です。
- 現実のニュースは、出典付きの小さな「反響カード」として追加できます。

悲劇や被害をプレイヤーの攻撃カードにはせず、技術・制度・知識の仕組みをカード能力として扱います。

## ローカル起動

```bash
python3 -m http.server 4173
```
