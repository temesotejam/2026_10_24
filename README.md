# CHRONICLE: TIPPING POINT

出典付きの史実・ニュースを「兆候」として観測し、予告される社会危機へ対応する一人用デッキ構築ゲームです。

## プレイ

[GitHub Pagesでプレイ](https://temesotejam.github.io/2026_10_24/)

## 中心ルール

- 8ターン、生活基盤・制度・公共圏の3領域を維持します。
- 毎ターン、出典付きの兆候を1つ記録します。
- 同じ領域の兆候3つで、恒久効果を持つ遺産が完成します。
- 次の危機と被害領域は事前に表示されます。
- 12枚の対応デッキから、回復・防護・制度化を選びます。
- 8ターン終了時に2つの遺産があり、全領域が維持されていれば勝利です。
- 現実の小さなニュースは出典付きで資料庫へ追加でき、ブラウザ内に保存されます。

事実データとゲーム効果は分離しています。災害や被害そのものを攻撃力・希少度として扱いません。
